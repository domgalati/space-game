# Foreman sample generation prompts

Generated with the built-in image_gen tool, one call per species, with transparent_background=true. References: the existing `space/assets/img/objects/foreman.png` and the prior NPC audit contact sheet. Source output retained in `sources/`; production-sized exports use nearest-neighbor sampling, binary alpha, and a limited palette via `export.cjs`.

## human

Use case: stylized-concept. Asset: one production map sprite for a low-bit NES-like planetary RPG. Input image 1 is the existing 24x24 human Foreman STYLE AND SCALE reference. Input image 2 is an audit sheet: use only its species anatomy and top-row map sprite style; the large portrait rendering is NOT the target detail level.
Create ONE full-body front-facing standing Foreman, centered, on actual transparent background. Output a 24x24 logical pixel sprite, drawn as a perfectly aligned 24-column by 24-row pixel grid. If delivered enlarged, each logical pixel must be an identical solid square and every edge align to that same 24x24 grid. The full canvas represents exactly 24x24 pixels. Occupy about 12-16 logical pixels wide and 22 logical pixels tall, with feet at row 22; leave one transparent row above and below. Large head about 6x7 logical pixels, small torso, separate boots and simple arms, matching the reference's body proportions. Only 8 opaque flat colors maximum plus transparency, hard stepped edges. NO antialiasing, gradients, dithering, lighting effects, texture, outlines within every little feature, or subpixel detail. NES-era economical pixel clusters, not 16-bit or modern high-detail pixel illustration. No ASCII, letters, labels, gridlines, border, ground, shadow, background or duplicate characters. Shared uniform: pale gray work shirt, charcoal/navy trousers and boots, tiny ochre Assembly supervisor shoulder accent, small ochre work tablet at one hip. Keep enough negative space between legs and beside arms. The result must remain readable after nearest-neighbor export to EXACT 24x24 RGBA PNG.
Subject: Human Foreman: warm tan face, very simple dark eyes, off-white industrial hard hat, human rounded ears. Straight slim silhouette close to the existing human foreman sprite. Keep helmet distinct from the face.
